EXPERIMENT 3
Perform Open Source Intelligence (OSINT) Gathering
Aim
To perform OSINT information gathering using Netcraft, WHOIS lookup, DNS reconnaissance, theHarvester and Maltego.
Requirements / Tools
Internet-connected browser and Kali Linux tools, as available in the laboratory. Use only a permitted domain.

Procedure
Select a permitted website or domain for the exercise.
Open Netcraft in a browser and enter the website address to view available technology and infrastructure information.
Use a WHOIS lookup service to view domain-registration information.
Perform DNS reconnaissance to identify available DNS records for the permitted domain.
Use theHarvester in Kali Linux to collect publicly available information, as demonstrated by the faculty.
Explore Maltego to understand how public information and relationships can be represented.
Record the information obtained from each tool.
Important Commands / Points
theHarvester -d <permitted-domain>


Observation / Expected Output
Information displayed may include domain details, DNS information, IP-related information, technology details and other publicly available data, depending on the tool and domain.
Result
Thus, OSINT information gathering was performed using the listed tools.
